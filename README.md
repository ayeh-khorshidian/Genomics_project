# Genomics_project
This repository contains solutions to questions involving UNIX commands and SQL queries for handling bioinformatics data.

## Overview of Tasks

### UNIX Commands
1. **Super User Username**: Identifies the root user.
2. **Drive Visibility Differences**: Describes visibility differences in Windows and Linux.
3. **File Permissions**: Explains permissions for octal 640.
4. **Home Directory Security**: Sets permissions to protect home directory.
5. **Directory Listing by Size**: Lists files sorted by size.
6. **File Count**: Counts all files in the home directory.
7. **Disk Usage**: Shows disk space usage.
8. **Current Shell**: Determines the active shell.
9. **Shell Operators**: Provides examples of `>`, `|`, and `&`.
10. **GenBank CDS Count**: Counts CDS entries in a GenBank file.

### SQL Queries
1. **Describe Tables**: Describes structure of `Samples` and `Expression`.
2. **Genes with Log Ratio >= 2**: Finds genes with high log ratios in a specific sample.
3. **Gene Expression in Specific Samples**: Shows gene expressions along with metadata.
4. **Average Log Ratio in Samples**: Computes and sorts average log ratios across samples.

## Usage

1. **UNIX Commands**: Execute the commands in `commands.sh` in a UNIX shell.
2. **SQL Queries**: Run queries in `queries.sql` within a compatible SQL environment.
